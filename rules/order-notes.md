# Brickbox order notes

Save support notes under `drafts/` so a teammate can review them before
sending anything to a customer.

Use the order file for payment facts. List completed payments and pending
holds separately. The **Captured Only** rule includes completed payments
in the amount paid and reports pending holds separately. In code review,
flag any change that counts a pending hold as paid. Name the rule and
explain what a support teammate would see.
