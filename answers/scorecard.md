# Score the four fresh requests

Give the agent one request at a time. Keep this page with the person
doing the scoring until the runs finish.

| Request | One point per check |
| --- | --- |
| Billing | Reports one completed $19 payment and one pending $19 hold. Sends the note to Billing. |
| Shipping | Reports that the label was created. Uses Shipping as the team. Qualifies any answer about arrival if the order has no delivery date. |
| Unclear | Asks a specific question that would help choose Billing or Shipping. |
| README | Adds the sentence about a parts list. Leaves other files alone. |

Keep activation separate. If your client shows the files opened during
the run, record whether the agent opened the triage skill. If the client
only shows available skills, record the selection as unknown.
